❓ Help & System FAQs

How accurate is the plagiarism scan engine?

The layout processes programmatic token hashes side-by-side to ensure precise validation checks matching identical and modified prose segments instantly.

Which file formats are supported for plagiarism scanning?

We currently support plain text files (.txt). For best results with Microsoft Word (.docx) or PDF documents, simply copy the text directly and paste it into the Text Scan tab.

Is my search history saved?

Yes. All completed scans are automatically logged to your identity session. You can view all previous scan dates, document names, similarity scores, and status updates anytime under the History tab.
